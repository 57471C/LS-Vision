# Operator View

The main screen used on the bench.

## Live view

- Uses the same paced preview path as Settings.
- Header shows capture resolution/fps and canvas fps.
- **Stop feed** / start feed control the preview.

## Snapshot and detect

- A readable barcode that matches a BoM can trigger a snapshot (or use the manual button).
- Snapshot is full resolution and is used for detection.
- Results appear in the right-hand panel: expected parts vs seen, with bounding boxes on the annotated image.

## ERP panel

An optional slide-over panel can open a configured URL (e.g. PLATS) for label printing. Controlled from Settings.
